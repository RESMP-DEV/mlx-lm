## `qwen3_next` baseline structure and mlx-lm registry wiring

Source: `/Users/kearm/mlx-lm/mlx_lm/models/qwen3_next.py`, 525 lines.

### Structure

- `ModelArgs` is a flat dataclass for hidden dimensions, full-attention interval, GDN geometry, MoE geometry, rope, and tied embeddings.
- `Qwen3NextRMSNormGated` uses `mx.fast.rms_norm`; gated output uses `precise_swiglu`.
- `Qwen3NextAttention` uses fused Q plus a sigmoid gate, separate K/V, `nn.RMSNorm`, `initialize_rope`, `KVCache.update_and_fetch`, and `scaled_dot_product_attention`.
- `Qwen3NextGatedDeltaNet` projects/reorders QKVZ and BA, keeps depthwise `nn.Conv1d` state in cache slot 0, normalizes Q/K through `gated_delta.normalize_qk`, calls `gated_delta_update`, stores SSM state in slot 1, and calls `cache.advance(S)`.
- `gated_delta_update` computes decay with `mx.exp`, `nn.softplus`, and `mx.sigmoid`. On GPU it dispatches custom `mx.fast.metal_kernel` implementations. The CPU/fallback path, `gated_delta_ops`, loops over `_gated_delta_step_ops`; that step uses elementwise multiply/add, reductions over the key dimension, `mx.where`, and `mx.stack`.
- `Qwen3NextSparseMoeBlock` uses precise softmax, `mx.argpartition`, `mx.take_along_axis`, `SwitchGLU`, a dense shared expert, and a sigmoid shared-expert gate.
- `Qwen3NextDecoderLayer` chooses GDN when `(layer_idx + 1) % full_attention_interval != 0`, otherwise full attention. MLP choice follows `decoder_sparse_step` and `mlp_only_layers`.
- `Qwen3NextModel(PipelineMixin, nn.Module)` owns embeddings, layers, final norm, pipeline communication, one SSM mask, and one full-attention mask.
- Top-level `Model` owns the text model and optional untied `lm_head`.

### Cache

- `Model.make_cache()` returns `ArraysCache(size=2)` for linear layers and `KVCache()` for full-attention layers (`qwen3_next.py:477-478`).
- Linear cache slot 0 is GDN convolution state; slot 1 is recurrent SSM state.
- `ArraysCache` serializes `[cache, left_padding, lengths]` and implements filter/extend/extract/merge in `/Users/kearm/mlx-lm/mlx_lm/models/cache.py:596-726`. PR #1788 defines model-local `_AttnCache`, `_BatchAttnCache`, `_IndexerCache`, and `_LayerCache` instead of modifying core cache.py.

### Quantization and MTP hooks

- `Model.sanitize()` discovers MoE layers, removes keys containing `mtp.` (`qwen3_next.py:489`), stacks expert projections into `switch_mlp`, transposes conv weights, and adds 1.0 to selected zero-centered norms.
- `Model.quant_predicate` requests 8-bit/64 only for `mlp.gate` and `shared_expert_gate`.
- `/Users/kearm/mlx-lm/mlx_lm/utils.py:474-535` calls `sanitize()` before applying external/per-module quantization.
- `/Users/kearm/mlx-lm/mlx_lm/utils.py:936-1004` invokes `model.quant_predicate` during `quantize_model`.
