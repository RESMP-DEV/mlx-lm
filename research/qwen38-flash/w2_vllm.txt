# Qwen4Exp / Qwen3.8-Flash-Next in vLLM and adjacent kernels

## Summary

- vLLM support is merged: [PR #53896](https://github.com/vllm-project/vllm/pull/53896), merged `2026-08-31T05:57:56Z`.
- The model is not under `vllm/model_executor/models/qwen4_exp.py`; it is at [`vllm/models/qwen4_exp/`](https://github.com/vllm-project/vllm/tree/main/vllm/models/qwen4_exp), with NVIDIA/AMD variants.
- Registry maps `Qwen4ExpForCausalLM`, `Qwen4ExpForConditionalGeneration`, and `Qwen4ExpMTP` to `vllm.models.qwen4_exp` in [`registry.py`](https://github.com/vllm-project/vllm/blob/main/vllm/model_executor/models/registry.py).
- Qwen4Exp extends Qwen3Next with HC multi-stream state, PLE n-gram conditioning, QSA sparse attention/side caches, and MTP using pre-final-mixer hidden state.
- PLE is model-internal conditioning, not lossless n-gram speculation; MTP is learned speculation and reuses step-0 QSA selections.
- Most acceleration beyond baseline is open/draft: PrimTS QSA, SM90 native QSA, FP8/NVFP4 QSA KV, fused draft metadata, FP8 MTP head, AMD fused pre-indexer/HC, CPU backend, and sequence parallelism.

4. **Configuration:** [`Qwen4ExpTextConfig`](https://github.com/vllm-project/vllm/blob/main/vllm/models/qwen4_exp/config.py) subclasses `Qwen3NextConfig`, adds HC/PLE/QSA fields, requires `indexer_kv_heads=1`, and requires block top-k `indexer_budget / indexer_compress_ratio` to be 512 or 2048.
5. **QSA:** [`qsa.py`](https://github.com/vllm-project/vllm/blob/main/vllm/models/qwen4_exp/nvidia/qsa.py) defines `QWEN4_EXP_QSA_TRITON`, supports BF16 main KV on merged main, and pending [#54846](https://github.com/vllm-project/vllm/pull/54846) adds FP8-E4M3/NVFP4 reads. Main KV is `FullAttentionSpec`; QSA also has raw and compressed indexer side caches in [`qsa_cache.py`](https://github.com/vllm-project/vllm/blob/main/vllm/models/qwen4_exp/common/qsa_cache.py).
6. **Top-k flow:** the indexer writes request-relative token indices plus a count into a packed int32 buffer. [`qsa_pre_indexer`](https://github.com/vllm-project/vllm/blob/main/vllm/models/qwen4_exp/nvidia/ops/qsa_pre_indexer.py) fuses norm/RoPE/key-store/compression when eligible; otherwise separate compression and decode/prefill selection ops run.
7. **MTP:** [`mtp.py`](https://github.com/vllm-project/vllm/blob/main/vllm/models/qwen4_exp/nvidia/mtp.py) uses the target’s pre-final-mixer multi-stream hidden state. `set_skip_topk(true)` selects QSA indices on MTP step 0 and reuses them on later steps.
8. **PLE:** [`ple_layer.py`](https://github.com/vllm-project/vllm/blob/main/vllm/models/qwen4_exp/nvidia/ple_layer.py) looks up n-gram embeddings, dequantizes selected rows, projects/norms/gates them, and adds a dilated depthwise short conv. It has its own recurrent state; it is not speculative or lossless lookahead.
9. **HC:** [`model.py`](https://github.com/vllm-project/vllm/blob/main/vllm/models/qwen4_exp/nvidia/model.py) wraps attention and MLP in `GatedResidual`, expands hidden state to `hc_count * hidden_size`, can delay combine, and returns both sampled and multi-stream hidden state.

## Architecture delta vs qwen3_next

- Reuses Qwen3Next GDN, dense attention projection conventions, and MoE.
- Adds HC multi-stream state and delayed combine/final mixer.
- Adds PLE as a second recurrent state and large n-gram lookup.
- Replaces ordinary full attention with QSA selected-token sparse attention plus indexer side caches.
- Adds MTP consuming multi-stream target hidden state and reusing QSA step-0 selections.
- GDN state remains `[batch, value_heads, value_dim, key_dim]`; PLE adds TP-replicated short-conv state; QSA adds `CircularBufferSpec`/`MLAAttentionSpec` side caches.
- vLLM GDN prefill chunk size is backend-dependent; fused decode state dtype selector is `{float32, bfloat16}`. MLX core’s fused chunk is `C=8`.

## MLX port implications

Already present locally:

- `mx.fast.scaled_dot_product_attention` supports GQA/MQA and masks.
- `mx.fast.gated_delta_update` and Metal kernels exist, including instantiation for `Dk=128`, `Dv=128`, `Hk=16`, `Hv=48`.
- mlx-lm already has Qwen3Next GDN, cache handling, MoE, and custom gated-delta kernels.
- `mx.conv1d` supports grouped dilated convolution.
- `mx.topk`, `argsort`, `cumsum`, and `logsumexp` can provide a correct eager indexer.

Needs new work:

- HC wrappers and later fused Metal HC kernels.
- Selective PLE embedding lookup/dequantization and PLE state rollback.
- Fused PLE gate/norm/conv Metal path.
- QSA side-cache metadata, compressed/raw key caches, paged top-k, expansion, and sparse gather attention.
- MTP runtime carrying multi-stream hidden state and QSA index reuse.
- FP8/NVFP4 dequantization if targeting common quantized checkpoints.
